# Security policy

## Supported versions

Karu is pre-1.0. Security fixes are applied to the current minor release and
to `main`; older prototype histories are not maintained.

| Version | Supported |
|---|---|
| 0.2.x | Yes |
| earlier | No |

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/asterisk-labs/karu/security/advisories/new>

Please include the affected version or commit, platform, a minimal reproducer,
and the expected impact. Do not include live credentials, bearer tokens,
signed URLs, account identifiers, or private bucket/object names. Replace them
with synthetic values before attaching logs.

Please allow the maintainers time to reproduce and fix the issue before public
disclosure. Ordinary bugs that do not expose data, credentials, integrity, or
availability can use the regular issue tracker.
