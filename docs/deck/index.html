Which ranges merge

Gap 1 MiB

KARU_COALESCE_GAP

The next read joins the request when the hole before it is at most 1 MiB.

reads requests A B C 512 KiB 2 MiB AdroppedBGET 1 CGET 2 hole 512 KiB≤ 1 MiB, joins hole 2 MiB> 1 MiB, new request

Ratio 16×

KARU_COALESCE_AMPLIFICATION

The next read joins only if the request then fetches at most 16 times the bytes asked.

reads requests A B C 768 KiB 768 KiB 32 KiB 32 KiB 32 KiB droppedGET 1 GET 2 832 KiB for 64 KiB asked13×, ≤ 16×, joins 1,632 KiB for 96 KiB asked17×, > 16×, new request

You only pass each read's offset and size. Karu measures the holes and ratios itself, with its defaults.

How big one request gets

Span 64 MiB

KARU_COALESCE_LIMIT

A request covers at most 64 MiB, from its first byte to its last.

reads requests A B C 512 KiB 512 KiB 64 MiB from the first byte ABGET 1 CGET 2 A + B = 48.5 MiB≤ 64 MiB, joins + C = 73 MiB> 64 MiB, new request

Parts 1024

KARU_COALESCE_PARTS

A request carries at most 1024 reads, even when they touch.

reads requests … read 1 read 1024 reads 1 to 1024GET 1 1025GET 2 1,024 readsfull, new request

Holes not to scale. Local files merge only ranges that touch, and a gap of 0 turns merging off.

Karu can also download whole objects

new in 0.5.0 
client.download(object, "scene.rumi")

One read of up to 1 MiB returns the first bytes, the size and the ETag. Each range asks for that ETag with If-Match and is written at its offset when it lands. The destination appears only after every range has landed, and an existing file is not replaced by default. A changed ETag or a cancel deletes the temporary file, so no partial destination ever appears.
